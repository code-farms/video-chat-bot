# **App Name**: VideoChat Hub

## Core Features:

- Video Upload: Allow users to upload a video file from their device.
- Video Preview: Display a preview of the uploaded video.
- Chat Window: Implement a chat window on the left side of the page for real-time text-based communication. Use Redux Toolkit to manage the chat state.

## Style Guidelines:

- Primary color: Neutral gray for the background (#F5F5F5).
- Secondary color: White (#FFFFFF) for panels and cards.
- Accent: Teal (#008080) for interactive elements and highlights.
- Use a responsive layout to adapt to different screen sizes.
- Divide the screen into two main sections: the video player area and the chat window on the left.
- Use clear and recognizable icons for video controls (play, pause, upload, etc.)
